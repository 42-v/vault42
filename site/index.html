WHAT IT IS

vault42 is a self-hosted identity authority. A single Go binary issues all session JWTs using RS256 with a strict algorithm whitelist and publishes keys at a JWKS endpoint for any resource server to verify.

No external IdP. No cloud. You run it. Stateless access tokens. Stateful refresh with replay-family revocation. PostgreSQL-backed with least-privilege roles. Embedded SPA or pure API.

  • One static binary — CGO_ENABLED=0, distroless, read-only fs.
  • RS256/JWKS resource-server model. Tokens are verifiable by any service.
  • Full session lifecycle: register, login, refresh, logout, MFA.

PROOF POINTS

RS256 ONLY
Algorithm whitelist rejects none, HS256, ES*, and all others at parse time. Rejects jku, jwk, x5u headers. 2048-bit RSA. 8 KB size cap.
JWKS ENDPOINT
GET /.well-known/jwks.json. Any resource server fetches public keys. Zero-downtime rotation. Retired keys retained for validation window.
FIDO2 / WEBAUTHN
Passkey registration and authentication. Security keys + platform authenticators. Works alongside TOTP + backup codes.
APPEND-ONLY AUDIT
DB-level enforcement. PostgreSQL triggers block UPDATE/DELETE on audit_log. vault_app role restricted to INSERT + SELECT only.
REFRESH ROTATION + REPLAY DEFENSE
Single-use refresh tokens. Family tracking. Replay of a used token nukes the entire family. Device fingerprint bound.
MINIMAL + HAND-ROLLED
Exactly three direct dependencies. JWT, TOTP, JWKS, fingerprint, constant-time, AES-GCM — implemented in stdlib or small internal packages.
RUNS ON A PI
Embedded profile: ~60-80 MB idle RAM, in-memory cache, 5 DB conns, auto-migrate. ARM64 build supported.
ARGON2ID + FINGERPRINT
46 MiB / 1 iter, NIST SP 800-63B. HIBP k-anonymity check. Every token carries device fingerprint hash.
