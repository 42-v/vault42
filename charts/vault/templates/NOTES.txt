0. FIRST-BOOT CREDENTIALS. This release mints credentials that are shown once and
   never again -- a seeded client secret per client{{ if .Values.adminGateway.enabled }}, the admin gateway's super_admin
   bootstrap password{{ end }}, and the admin token when secrets.keys.adminToken is unset.
   They are deliberately not in the pod log. They are written to
   {{ .Values.firstBootCredential.path }} inside the pod, mode 0600.
{{- if not .Values.firstBootCredential.existingClaim }}

   That volume is memory-backed, so it is gone when the pod is. Read it before
   anything restarts the pod, or set firstBootCredential.existingClaim to a
   PersistentVolumeClaim and read it from there at your leisure.
{{- end }}

   The image is distroless, so it has no shell to `kubectl exec cat` with and no
   tar for `kubectl cp`. Attach an ephemeral container that can see the
   filesystem:

     kubectl debug -n {{ .Release.Namespace }} -it deploy/{{ include "vault.fullname" . }} \
       --image=busybox --target={{ .Chart.Name }} \
       -- cat /proc/1/root{{ .Values.firstBootCredential.path }}
{{- if gt (int .Values.replicaCount) 1 }}

   This release runs {{ .Values.replicaCount }} replicas and each has its own copy of that volume.
   Only the pod that won the race actually minted anything, so if the file is
   absent, try the others -- or use a claim, which gives one place to look.
{{- end }}

{{ end -}}
1. Get the application URL:
{{- if .Values.ingress.enabled }}
{{- range $host := .Values.ingress.hosts }}
  https://{{ $host.host }}
{{- end }}
{{- else if contains "NodePort" .Values.service.type }}
  export NODE_PORT=$(kubectl get --namespace {{ .Release.Namespace }} -o jsonpath="{.spec.ports[0].nodePort}" services {{ include "vault.fullname" . }})
  export NODE_IP=$(kubectl get nodes --namespace {{ .Release.Namespace }} -o jsonpath="{.items[0].status.addresses[0].address}")
  echo http://$NODE_IP:$NODE_PORT
{{- else if contains "ClusterIP" .Values.service.type }}
  kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ include "vault.fullname" . }} 8080:{{ .Values.service.port }}
  echo http://localhost:8080
{{- end }}

2. Check health:
  curl http://localhost:8080/healthz

3. Register a client:
  kubectl exec -n {{ .Release.Namespace }} deploy/{{ include "vault.fullname" . }} -- \
    /vault add-client --admin-token "$(cat /run/secrets/{{ .Values.secrets.keys.adminToken }})" \
    --name "frontend" --role "frontend" --scopes "user:read,user:write"

4. JWKS endpoint:
  /.well-known/jwks.json

5. OIDC discovery:
  /.well-known/openid-configuration
